# ODDB: Ocular Disease Database

Source repository: https://github.com/UmairSeemab/ODDB

Research website: https://www.oculardiseases.fi/

ODDB links ocular diseases, genes, variants, drugs and clinical evidence.
The PHP APIs query MariaDB. JavaScript displays searchable graphs and charts.
The app includes browsing, graph expansion, evidence filters, disease/drug
comparison, path finding, saved-session validation, publication exports,
statistics, documentation, contact information and frozen data downloads.

This is the **github package**, generated by packaging helper 0.8.8.
The app files are copied from the current `ODDB_v1_webapp_v0.4` folder. That
folder name is not a claim that every component has the same release version.

## Layout

| Path | Purpose |
| --- | --- |
| app/public/ | PHP pages, APIs, CSS, JavaScript, images and SVG assets |
| app/config/ | Release catalog used by the app |
| app/scripts/ and app/sql/ | Web taxonomy/catalogue scripts and historical migrations, in the GitHub package |
| retnet_pipeline/ | Scientific pipeline code and provenance, in the GitHub package |
| retnet_pipeline/releases/ | Checksummed release inventory; actual downloads in the cPouta package |
| schema/ | Exported schema, exact table counts and validation expectations |
| deploy/ and compose.yaml | PHP, MariaDB and optional Caddy HTTPS deployment |
| ops/ | Credential initialization, import, validation, backup and server controls |
| docs/ | Publication, deployment and browser acceptance instructions |
| database/ | Private complete SQL export and original collector metadata, cPouta only |
| package_manifest.json and SHA256SUMS.txt | Package contents and checksums |

The `app` and `retnet_pipeline` folders remain siblings. This preserves the
download.php path rules and requires no page or API functionality change.
Docker serves only `/srv/oddb/app/public`.

## Production deployment

ODDB v1 is deployed at https://oculardiseases.fi using CSC cPouta,
Nginx, Let's Encrypt, Docker, PHP and MariaDB.

See [production deployment documentation](docs/PRODUCTION_NGINX.md)
and the [Nginx configuration example](deploy/nginx/oddb.conf.example).

Caddy remains an optional deployment alternative and is not used
on the current production server.

## Requirements and running

Python 3.9+ is needed for the helpers. Running the app with this deployment uses
Docker Engine, Docker Compose, PHP 8.4 / Apache with PDO MySQL and mbstring, and
MariaDB 11.4. The pipeline has its own existing Python requirements files.

For the cPouta package, follow docs/CPOUTA.md. For the GitHub source package,
obtain the matching SQL snapshot and the release files identified by
retnet_pipeline/releases/release_inventory.json before running the deployment.
The source package alone has neither the complete SQL snapshot nor bulk data.

With an existing local MariaDB database, run from this package root:

```bash
ODDB_DB_HOST=127.0.0.1 ODDB_DB_PORT=3306 ODDB_DB_NAME=oddb_v1 \
ODDB_DB_USER=YOUR_READ_ONLY_USER ODDB_DB_PASSWORD='YOUR_LOCAL_PASSWORD' \
/opt/lampp/bin/php -S 127.0.0.1:8081 -t app/public
```

Set actual local credentials privately. The PHP built-in server is for local
testing. GitHub Pages cannot execute this PHP application.

## Biomedical literature mining

The repository preserves a historical PubMed/BioBERT-based
biomedical named-entity recognition utility:

- [BioBERT PubMed extractor](NLP/biobert_pubmed_extractor.py)
- [Installation and usage](NLP/README.md)
- [Scientific provenance](NLP/PROVENANCE.md)

The tool retrieves PubMed records, extracts candidate disease,
gene and drug entities, identifies study-related terminology,
and generates JSONL and CSV outputs.

This utility is provided for methodological transparency.
Its inclusion does not establish that its outputs contributed
to the validated ODDB v1 database. Database integration and
scientific performance require separate verification.

## Dataset provenance

The export contains 36 base tables. There are 33 catalogued
downloadable files. Exact counts are in schema/table_counts.tsv. Provenance and
source licenses must be assessed from their original sources; the application
does not establish permission to redistribute all upstream data.

Raw downloads, temporary reports, the old ODDB-main website, obsolete app
versions, UI patch backups, SQL data dumps and credentials are excluded from
the GitHub package. The existing app and database are never edited by packaging.
No code is pushed and no DNS records are changed.

## Evidence interpretation

Disease-specific drug evidence is distinct from drug-target pharmacology and
target overlap. Target overlap is discovery context. Trial investigation does
not establish approval. Disease-variant evidence is distinct from gene validity.

## Interactive scientific statistics

The Statistics page includes precomputed release-based chromosome, gene, variant, disease and trial visualizations, adjustable Top-N rankings (20, 30, 40, custom and all), and a focused disease–gene–drug network. See [the statistics implementation and validation guide](docs/STATISTICS_ENHANCED.md). The JSON datasets are generated from the validated ODDB v1 database and must be included in each release.
