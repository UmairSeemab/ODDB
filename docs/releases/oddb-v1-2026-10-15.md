## Scope and reproducibility

The source release excludes full database records, downloadable datasets, country lookup ranges, visitor records, credentials, TLS keys and private hosting backups. Four database views are omitted from the enriched schema export. Earlier schema and deployment files remain in the repository as historical material. They are not a verified complete deployment configuration for the enriched application.

Scientific scripts and source manifests document part of the preparation history. Full reproduction requires the matching permitted source data, mappings, curation decisions, recent enrichment workflows and deployment assets. A clean-host deployment of this source package has not been verified.

The original publication ZIP passed CRC and listed SHA-256 checks. The repository inventory was refreshed for this release. Neither integrity check establishes scientific validity. Trial investigation does not establish efficacy or approval. Shared-target overlap remains discovery context.
